# Internationalization

MindContext treats interface language and knowledge language as separate
concerns.

## Current UI locales

The web application currently ships with embedded resources for:

- English (`en`)
- Spanish (`es`)

The preference is browser-local:

```text
mindcontext.locale = system | en | es
```

`system` resolves from `navigator.languages` and reacts to the browser
`languagechange` event. Unsupported system languages fall back to English.

Translation resources are bundled with the application. Changing interface
language does not require a translation CDN or another network request.

## Separation of language concerns

These concepts MUST remain independent:

1. **Interface locale** — labels, dialogs, errors and application chrome.
2. **Starter/template locale** — the language used when generating optional
   onboarding Markdown such as a PARA starter.
3. **Note language** — entirely controlled by the user and never constrained by
   the interface or template locale.

A workspace is therefore not assigned a mandatory language. English, Spanish,
Chinese and other languages can coexist in ordinary Markdown files.

## Canonical-content rule

Changing the interface locale MUST NOT rewrite existing Markdown, paths,
frontmatter, tags or aliases.

New blank notes are created empty instead of inserting an English heading.
Templates may intentionally generate localized Markdown, but their locale must
be an explicit template choice.

## Accessibility

The resolved interface locale is written to the document `lang` attribute.
ARIA labels and dialog names use the same translation layer as visible UI.

## Adding another locale

A new UI locale should:

1. extend `SupportedLocale`;
2. add a complete resource bundle;
3. appear in the language selector;
4. have browser tests for switching/persistence;
5. not introduce assumptions about canonical workspace folder names.

Search and semantic retrieval remain language-independent concerns. Their own
tokenization/model capabilities must be evaluated separately from UI i18n.
